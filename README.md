# Dark Realm

Браузерная пиксельная карточная дуэль в тёмном фэнтези. Механика повторяет
Tales of Tribute из The Elder Scrolls Online: драфт покровителей, таверна,
монеты, сила и престиж, агенты, контракты, комбо и благосклонность покровителей.
Названия, тексты и графика свои: каждая иллюстрация рисуется кодом как
пиксель-арт 128×128.

## Режимы

- **Против бота**: всё считается в браузере.
- **Туториал**: короткая партия до 20 престижа против мягкого бота. Подсказки ведут через выбор покровителей и первые ходы, пока они на экране, работает только подсвеченное (`src/engine/tutorial.ts`, `src/ui/tutorial.ts`).
- **Комната**: один игрок создаёт комнату и отправляет код или ссылку, второй
  подключается. Связь идёт напрямую между браузерами через WebRTC (PeerJS),
  своего сервера нет. Движок работает у создателя комнаты.

## Разработка

```bash
npm install
npm run dev        # игра на http://localhost:5173
npm test           # тесты движка и партии бот против бота
npm run build      # сборка в dist/
```

`art-preview.html` в dev-режиме показывает все пиксельные рисунки.

## Структура

- `src/engine/cards.ts`: покровители и карты (данные). Новые карты добавляются сюда.
- `src/engine/engine.ts`: правила, чистая функция `applyAction(state, player, action)`.
- `src/engine/bot.ts`: бот.
- `src/art/`: генератор пиксель-арта.
- `src/net/room.ts`: комнаты через PeerJS.
- `src/ui/`, `src/main.ts`: интерфейс.

### Как добавить карту

Добавьте запись в `CARDS` в `src/engine/cards.ts`:

```ts
{ id: 'crows_new', name: 'Новая карта', patron: 'crows', cost: 4, type: 'action', copies: 1,
  play: [power(2)], combo: { 2: [draw(1)] }, art: 'skull', seed: 42 },
```

`art` — один из сюжетов из `SUBJECTS` в `src/art`, `seed` меняет детали рисунка.

## Деплой

Workflow `.github/workflows/pages.yml` собирает игру и выкладывает на GitHub Pages
при каждом пуше в `main`. В настройках репозитория (Settings → Pages) источником
должен быть выбран **GitHub Actions**.
