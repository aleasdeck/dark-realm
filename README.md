# Dark Realm

Браузерная пиксельная карточная дуэль в тёмном фэнтези. Механика повторяет
Tales of Tribute из The Elder Scrolls Online: драфт покровителей, таверна,
монеты, сила и престиж, агенты, контракты, комбо и благосклонность покровителей.
Названия, тексты и графика свои. Иллюстрации постепенно заменяются
нарисованными артами; у карт без арта картинку рисует код как пиксель-арт 128×128.

## Режимы

- **Против бота**: всё считается в браузере. Перед партией выбирается сложность: Лёгкий покупает наугад и не взывает к покровителям, Средний играет по простым правилам, Сложный перебирает варианты до конца своего хода и оценивает колоды, агентов и благосклонность обоих игроков (`src/engine/botHard.ts`). Выбор запоминается.
- **Туториал**: короткая партия до 20 престижа против мягкого бота. Подсказки ведут через выбор покровителей и первые ходы, пока они на экране, работает только подсвеченное (`src/engine/tutorial.ts`, `src/ui/tutorial.ts`).
- **Комната**: один игрок создаёт комнату и отправляет код или ссылку, второй
  подключается. Связь идёт напрямую между браузерами через WebRTC (PeerJS),
  своего сервера нет. Движок работает у создателя комнаты.
  Если кто-то из игроков обновил страницу, вылетел или связь зависла, партия
  не пропадает: оба возвращаются в неё сами, а оставшийся видит, что соперник
  переподключается. Партия хранится в браузере создателя комнаты 6 часов.
- **Рейтинг**: таблица игроков по именам, только сетевые партии. Партия засчитывается, когда оба игрока прислали один и тот же результат; имя закреплено за устройством секретным ключом; рейтинг по Эло со старта 1000. Хранится в Google Таблице: `server/rating.gs` (Apps Script) разворачивается как веб-приложение, его адрес вписывается в `RATING_URL` в `src/net/rating.ts`. Пока адрес пустой, экран рейтинга говорит, что таблица не подключена, и партии никуда не отправляются.

### Как подключить рейтинг

1. Создайте Google Таблицу, откройте «Расширения → Apps Script», замените код содержимым `server/rating.gs`, сохраните.
2. «Начать развёртывание → Новое развёртывание», тип «Веб-приложение», запуск от своего имени, доступ «Все». Разрешите доступ к таблице.
3. Скопируйте адрес вида `https://script.google.com/macros/s/…/exec` в `RATING_URL`.

Листы «Рейтинг», «Партии» и «Заявки» появятся сами. Чтобы отменить партию, удалите её строку в «Партии» и выберите в таблице «Рейтинг → Пересчитать рейтинг». Пустая ячейка «Ключ» освобождает имя для нового устройства. После правки скрипта нужно «Управление развёртываниями → Изменить → Новая версия», адрес остаётся прежним.

## Разработка

```bash
npm install
npm run dev        # игра на http://localhost:5173
npm test           # тесты движка и партии бот против бота
npm run build      # сборка в dist/
```

`art-preview.html` в dev-режиме показывает все пиксельные рисунки.

## Структура

- `src/engine/cards.ts`: покровители и карты (данные). Новые карты добавляются сюда.
- `src/ui/unlocks.ts`: какие закрытые покровители открыты у игрока. Шесть покровителей открываются по числу побед над ботом любого уровня и онлайн (туториал не считается; открытые раньше по счётчику партий остаются открытыми): Богомол за 5, Змей за 10, Бык за 20, Олень за 30, Паук за 40, Спрут за 50. До открытия они видны в драфте серыми плитками с числом оставшихся побед. `?unlock=all` в адресе открывает всех для проверки.
- `src/engine/engine.ts`: правила, чистая функция `applyAction(state, player, action)`.
- `src/engine/bot.ts`: бот (уровни Лёгкий и Средний, мягкий бот туториала), `src/engine/botHard.ts`: Сложный, `src/ui/botWorker.ts`: Сложный думает в фоновом потоке. `scripts/duel.ts`: партии бот против бота для настройки уровней.
- `src/art/`: генератор пиксель-арта; `src/art/custom.ts` подставляет нарисованные арты из `src/assets/`.
- `src/net/room.ts`: комнаты через PeerJS.
- `src/net/rating.ts`: отправка результатов сетевых партий в рейтинг и загрузка таблицы; `server/rating.gs`: сама таблица (Google Apps Script).
- `src/net/saved.ts`: сохранение сетевой партии для возврата после перезагрузки.
- `src/ui/`, `src/main.ts`: интерфейс.

### Как добавить карту

Добавьте запись в `CARDS` в `src/engine/cards.ts`:

```ts
{ id: 'crows_new', name: 'Новая карта', patron: 'crows', cost: 4, type: 'action', copies: 1,
  play: [power(2)], combo: { 2: [draw(1)] }, art: 'skull', seed: 42 },
```

`art` — один из сюжетов из `SUBJECTS` в `src/art`, `seed` меняет детали рисунка.

### Как добавить нарисованные арты

1. Сложите картинки колоды в одну папку. Карта называется так же, как в игре (`Удар когтем.png`), эмблема называется `Эмблема покровителя <Имя>.png` (`Эмблема покровителя Ворон.png`). Регистр и ё/е не важны, имя можно заменить на id (`crows_scratch.png`). Карты квадратные, от 512×512, без рамки и текста. Эмблема — круглый медальон на прозрачном или сплошном чёрном фоне.
2. Запустите `python3 scripts/import-art.py "<папка>"` (нужен Pillow: `python3 -m pip install pillow`). Скрипт кладёт карты в `src/assets/cards/<id>.webp` 512×512, а эмблему в `src/assets/patrons/<id>.webp` 256×256. Чёрный фон эмблемы он делает прозрачным, а медальон вписывает в круг. В конце печатает файлы без пары (`NO MATCH`) и карты колоды, у которых ещё нет арта.
3. Больше ничего менять не нужно: игра находит файлы по имени и загружает их при старте, ещё в меню. Карты без файла остаются с пиксель-артом.
4. Рубашка карты и фоны лежат отдельно и подключены в `src/style.css`: `src/assets/ui/card_back.webp` (360×512) и `src/assets/bg/bg_game_portrait|landscape.webp`, `bg_menu_portrait|landscape.webp`. Новую картинку кладут под тем же именем; если файла не будет, остаются фоны и рубашка, нарисованные в CSS.
5. Иконки интерфейса: `python3 scripts/import-icons.py "<папка с ui/*.png>" [иконка приложения.png]`. Файлы называются как в таблице иконок (`menu.png`, `res_coin.png`, `fx_draw.png`…). Скрипт кладёт их в `src/assets/icons/<id>.webp` в тройном размере показа, а `favicon.png` и иконку приложения в `src/assets/app/`. Кнопки и значки берут их по имени через `src/ui/icons.ts`; иконки ресурсов, цены и прочности подключены в `src/style.css`.
6. Проверьте, что стол помещается в экран без прокрутки на iPhone SE, iPhone 13, Pixel 7 и в альбомной ориентации.

## Деплой

Workflow `.github/workflows/pages.yml` собирает игру и выкладывает на GitHub Pages
при каждом пуше в `main`. В настройках репозитория (Settings → Pages) источником
должен быть выбран **GitHub Actions**.
